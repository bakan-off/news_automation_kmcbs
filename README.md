Веб-приложение, разработанное для **МУК «Кондинская межпоселенческая централизованная библиотечная система» (МУК Кондинская МЦБС)**. Сервис автоматизирует сбор новостных материалов от сотрудников и филиалов библиотечной системы, централизованную выгрузку медиафайлов в облачное хранилище и доставку готовых к публикации постов контент-менеджеру, а также прием заявок на удаленную техническую поддержку.

---

## ✨ Основные возможности

### 1. Публикация новостей (`/`)
* **Авторизация сотрудников**: вход по единому коду доступа с указанием имени автора или названия филиала библиотеки (сохраняется в сессии).
* **Структурированный ввод материала**:
  * Название новости и выбор возрастного ценза (`0+`, `6+`, `12+`, `16+`, `18+`).
  * Многострочное поле описания с автоматической подстройкой высоты и полным сохранением структуры абзацев при вставке текста из MS Word, браузера или мессенджеров.
* **Умная работа с хештегами**:
  * Панель быстрого выбора популярных рубрик (`#КМЦБС`, `#Вбиблиотеке`, `#ДетиРулят86`, `#ЧтоПочитать`, `#БиблиоКаникулы` и др.) в один клик.
  * Валидация формата хештегов (поддержка кириллицы, включая `Ё/ё`, латиницы и цифр) и автоматическое разделение слитно введенных тегов пробелами (`#тег1#тег2` → `#тег1 #тег2`).
* **Мультизагрузка файлов с предпросмотром**:
  * Поддержка перетаскивания (**Drag-and-Drop**) и стандартного выбора файлов.
  * Отображение миниатюр для фотографий и тематических иконок для видео, PDF и документов.
  * Возможность удалить любой прикрепленный файл из списка перед отправкой.
  * Контроль ограничений: до **10 файлов** общим объемом до **500 МБ**.
* **Интеграция с Облаком Mail.ru (WebDAV)**:
  * Для каждой новости автоматически создается отдельная папка с уникальным именем по дате и времени (`ДДММГГГГ-ЧЧММСС`).
  * Безопасная очистка имен файлов с полным сохранением русских букв и защитой от перезаписи одноименных файлов.
* **Готовое к публикации письмо («Скопировал — Вставил»)**:
  * Верхняя часть письма формируется без лишних технических меток и рамок, с выверенными пустыми строками-отступами: после заголовка, между абзацами, перед подписью библиотеки и перед хештегами. Редактору достаточно выделить текст в почте, скопировать и сразу вставить в публикацию.
  * Нижний служебный блок письма содержит прямую ссылку на папку в Облаке Mail.ru, ссылки на каждый загруженный файл, список выбранных площадок и кнопки быстрого перехода в админ-панель сайта и соцсети.

### 2. Запрос на удалённое подключение (`/remote_request`)
* Форма быстрой подачи заявки на техническую помощь (доступна без авторизации).
* Выбор способа описания проблемы: устно по телефону при подключении или текстовое описание.
* Выбор программы для удаленного доступа (**AweRay**, **TeamViewer**, **AnyDesk**, **Ассистент**) с прямыми ссылками на скачивание.
* Передача реквизитов доступа текстом (ID / пароль) либо прикреплением скриншота экрана (встроена визуальная подсказка с примером скриншота для AweRay).
* Мгновенная отправка заявки со скриншотом во вложении на почту специалиста.

### 3. Удобство и полная автономность
* **Тема «День / Ночь»**: переключение между темным и светлым оформлением в модальном окне настроек с сохранением выбора в `localStorage` без мерцания при перезагрузке страницы.
* **Независимость от внешних CDN**: официальный дистрибутив **Bootstrap 5.3.3** (CSS + JS Bundle) встроен локально в проект, что гарантирует стабильную загрузку интерфейса даже при блокировках или недоступности зарубежных CDN.

## ⚙️ Переменные окружения

Для работы приложения используются переменные окружения (задаются в панели управления **Timeweb Cloud** или в локальном файле `.env`):

| Переменная | Описание | Пример значения |
| :--- | :--- | :--- |
| `SECRET_KEY` | Секретный ключ Flask для подписи сессионных cookie | `случайная_строка_символов` |
| `USER_COD` | Логин для входа сотрудников в форму публикации новостей | `kmcbs_user` |
| `PASSWORD_COD` | Пароль для входа сотрудников | `ваш_пароль` |
| `WEBDAV_LOGIN` | Почтовый ящик аккаунта Облака Mail.ru | `muk_kmcbs@mail.ru` |
| `WEBDAV_PASSWORD` | Пароль приложения для доступа к Облаку Mail.ru по WebDAV | `пароль_приложения_webdav` |
| `SENDER_EMAIL` | Почтовый ящик отправителя уведомлений (SMTP Mail.ru) | `muk_kmcbs_smi@mail.ru` |
| `SENDER_PASSWORD` | Пароль приложения для отправки почты через `smtp.mail.ru:465` | `пароль_приложения_smtp` |
| `RECEIVER_EMAIL` | Почтовый ящик получателя новостей и заявок | `editor@mail.ru` |

## 🚀 Локальный запуск и тестирование

1. **Клонируйте репозиторий и перейдите в папку проекта:**
   ```bash
   git clone https://github.com/bakan-off/news_automation_kmcbs.git
   cd news_automation_kmcbs
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Создайте файл `.env`** в корне проекта и укажите переменные окружения из таблицы выше.

4. **Запустите сервер для разработки:**
   ```bash
   python app.py
   ```
   Приложение будет доступно по адресу `http://127.0.0.1:5000`.

5. **Запуск автоматических тестов:**
   В проекте предусмотрен тестовый набор `test_suite.py`, проверяющий доступность статики, авторизацию, очистку имен файлов с кириллицей, форматирование абзацев и хештегов в HTML-письме, а также обработку ошибок SMTP/WebDAV:
   ```bash
   python test_suite.py
   ```

## ☁️ Деплой на Timeweb Cloud

Приложение настроено для автоматического развертывания в сервисе **Timeweb Cloud Apps** из подключенного репозитория GitHub. Конфигурация описана в файле [`timeweb.yml`](timeweb.yml):

```yaml
version: '1.0'

services:
  web:
    build: .
    command: gunicorn --bind 0.0.0.0:8000 --timeout 300 --workers 2 app:app
    ports:
      - "8000:8000"
```

* Параметр `--timeout 300` (5 минут) позволяет беспрепятственно загружать большие видеоролики и архивы фотографий (до 500 МБ) в Облако Mail.ru без принудительного обрыва соединения воркером Gunicorn.
* Параметр `--workers 2` обеспечивает параллельную обработку запросов нескольких пользователей.
